# Web Development ABL Assignment

## Selected case studies (from circular)
1. Personal Portfolio Website
2. Online Learning Platform Interface
3. Online Food Ordering Website

## Files
- index.html — assignment landing page and links
- personal-portfolio.html — profile, education, skills, hobbies, projects, achievements, resume/contact, responsive design, animation and navigation
- online-learning-platform.html — course categories, course cards, instructors, descriptions, objectives, enrollment demo buttons, progress indicators and category filters
- online-food-ordering.html — restaurant details, categories, food cards, prices, offers, reviews, demo order buttons and responsive navigation

## Syllabus mapping
Unit I: HTML structure/elements, CSS syntax, class attributes, text and background colors, container elements.
Unit II: font family/size, text decoration, box model, width/height, borders, padding/margin, viewport, responsive/mobile-first design, typography, UI principles and accessibility.
Unit III: HTML5 semantic elements, hyperlinks, anchor navigation and web infrastructure basics.

## Run
Open index.html in a browser. No build tools required.

## Notes
Enrollment and food-order buttons are front-end demo interactions, not real backend services. Replace sample contact, college, instructor and restaurant information with accurate details before submission. Add your real resume/certificates if required. Screenshots will be stored in screenshots/ when captured.
