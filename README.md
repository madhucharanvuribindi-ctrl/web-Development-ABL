# Web Development ABL — 3 Case Studies

This repository contains three separate responsive HTML/CSS projects:

1. **Personal Portfolio Website** — profile, projects, skills and contact section.
2. **Online Learning Platform** — course categories, course cards and learning progress.
3. **Online Food Ordering Website** — menu items, offers and food ordering interface.

## Project folders
- `01-personal-portfolio/` — `index.html`, `style.css`, desktop/mobile screenshot previews
- `02-online-learning-platform/` — `index.html`, `style.css`, desktop/mobile screenshot previews
- `03-online-food-ordering/` — `index.html`, `style.css`, desktop/mobile screenshot previews

## Run locally
Open a project's `index.html` in a browser. Each page loads its own stylesheet. These are front-end assignment demos; checkout, enrollment, and contact actions are not connected to a backend.
